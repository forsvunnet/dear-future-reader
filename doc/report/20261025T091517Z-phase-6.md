# Phase 6: Web UI

## Done

- `/` lists the things as a tree, with the ID, the name and the status. Each name links to the page of the thing.
- `/things/{id}` shows the name, the status, the parent and the context files in order. The body shows as Markdown, the frontmatter as YAML. An unknown ID gives 404.
- **Edit** opens the full content of one file in a textarea. **Save** writes the file and a log line with the session `web`.
- `SaveFileIfUnchanged`: writes the file only when its sha1 is the same as when the editor opened it. The check and the write happen while the thing is locked.
- The Web UI is in the Dfr domain: `domain/Dfr/src/Livewire/`, `domain/Dfr/resources/views/` and `domain/Dfr/routes/web.php`.
- The welcome page of Laravel is removed.
- Fix: `php artisan serve` did not pass `HOME` to the PHP server, so the Web UI looked for the things in `/.dfr`. The Dfr service provider adds `HOME` to the variables that `serve` passes on. `LoadThingsRoot` now fails when `HOME` is empty.
- `WebUiTest` covers the list, the file page, escaped HTML, archived files, 404, save, the log line, the two save conflicts and the files that edit must not open.

## Decisions

- **Web UI in the Dfr domain**: STYLE.md says a domain knows only itself and the app. A separate Web domain would use the Dfr actions directly and break that rule.
- **Livewire class components with dependencies in `boot`**: Livewire makes the component itself, so constructor injection is not possible. `boot` lists the dependencies in one place.
- **Save checks for changes**: sessions write the files while a person edits them. Without the check, a save would remove the change of a session without a sign.
- **The text stays in the editor after a failed save**: the person can copy it. This also holds when a session archived or removed the file.
- **Edit only opens a file from the list of the thing**: the filename comes from the browser, so it must not point at a dot file or outside the folder.
- **Markdown with escaped HTML and no unsafe links**: a file can contain any text, and raw HTML must not run in the browser.
- **Line breaks become `\n` on save**: a textarea sends `\r\n`. The CLI writes `\n`.
- **Log session `web`**: the browser has no Claude Code session. `web` tells a reader of `dfr $ID log` that a person made the change.
- **No search box**: the list shows all things on one page. The search of the browser finds a thing.
- **Markdown styles in `app.css`**: a few rules for the `.markdown` class. The Tailwind typography plugin would be a new dependency.

## Open

- The Web UI has no login. It is safe only while the server listens on `127.0.0.1`, which is the default of `php artisan serve`.
- The Web UI cannot change the status, the parent, the name or the order of the files, and cannot make or archive files. Phase 6 asked only for read and edit.
- The page does not update when a session writes a file. A reload shows the new content.
- Phase 5 has no report. Its step 3, a real task over two or more sessions, is not checked yet. This phase was done in one session with the `dfr` skill, thing `mpg`.
